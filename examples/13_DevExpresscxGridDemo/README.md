# 13. DevExpress QuantumGrid (TcxGrid) 기초 실습 데모

이 예제는 델파이 대표 3rd Party 그리드 컴포넌트인 **DevExpress QuantumGrid (TcxGrid)**의 핵심 기능(그룹핑, 요약 합계, 동적 컬럼 생성, 엑셀 출력)을 학습하는 기초 실습 프로젝트입니다.

---

## 1. 주요 학습 내용
- **컬럼 그룹핑 (Drag & Drop Grouping)**
- **하단 요약 Footers (Sum, Count, Average)**
- **동적 컬럼 생성 (Runtime Column Creation)**
- **엑셀 익스포트 (`ExportGridToExcel`)**
