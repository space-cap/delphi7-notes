# 05-0. 델파이 7 컴포넌트 팔레트(Component Palette) 탭별 완벽 가이드 🧰

> 💡 **초초보자를 위한 한 줄 요약**  
> 델파이 7 화면 상단에 길게 늘어서 있는 탭들이 바로 **컴포넌트 팔레트(Component Palette)**입니다! 화면을 꾸밀 레고 부품들이 카테고리별로 정돈된 **부품 백화점**입니다.
> 
> 📘 **이미지의 25여 개 탭 전체 컴포넌트 완벽 대백과사전**: [docs/05-vcl/palette/README.md 바로가기](palette/README.md)

---

## 📸 컴포넌트 팔레트 전체 모습

델파이 7 상단에는 아래처럼 수많은 탭(Standard, Additional, Win32, System, Dialogs 등)이 준비되어 있습니다.

```text
[ Standard ] [ Additional ] [ Win32 ] [ System ] [ Data Access ] [ Data Controls ] [ Dialogs ] [ Indy ... ]
```

---

## 🧰 실무 필수 7대 핵심 탭 완벽 정리!

### 1. `Standard` 탭 (가장 기본적인 기본 부품) 🔴
프로그램을 만들 때 가장 기본으로 사용하는 표준 UI 컴포넌트 모음입니다.

| 컴포넌트 | 기능 및 비유 |
| :--- | :--- |
| **`TMainMenu`** | 창 상단에 위치하는 기본 메뉴바 (`파일`, `편집`, `도움말` 등) |
| **`TPopupMenu`** | 마우스 우클릭했을 때 나오는 미니 팝업 메뉴 |
| **`TLabel`** | 화면에 보여주는 안내 글자 텍스트 |
| **`TEdit`** | 사용자가 한 줄 입력하는 글자 상자 |
| **`TMemo`** | 여러 줄 글자를 입력하거나 로그를 남기는 장문 상자 |
| **`TButton`** | 클릭하는 일반 버튼 |
| **`TCheckBox`** | 체크 표시(V) 선택 박스 |
| **`TRadioButton`** | 여러 개 중 딱 하나만 선택하는 동그라미 단일 선택 버튼 |
| **`TComboBox`** | 아래로 목록이 드르륵 열리는 드롭다운 선택상자 |
| **`TListBox`** | 목록을 나열하여 보여주는 리스트 박스 |
| **`TPanel`** | 화면 구역을 나누거나 컴포넌트들을 담아두는 바탕 판(패널) |

---

### 2. `Additional` 탭 (조금 더 유용한 기능성 부품) 🟠
`Standard` 탭의 부품보다 기능이 풍부한 확장 UI 컴포넌트 모음입니다.

| 컴포넌트 | 기능 및 비유 |
| :--- | :--- |
| **`TBitBtn`** | 버튼 안에 예쁜 아이콘 그림(OK, Cancel 등)을 넣을 수 있는 버튼 |
| **`TSpeedButton`** | 툴바에 들어가는 경량 버튼 (마우스 올리면 튀어나오는 스타일) |
| **`TMaskEdit`** | 주민번호(`900101-1234567`), 전화번호 포맷에 맞게 입력을 제한하는 상자 |
| **`TStringGrid`** | 엑셀 표처럼 가로/세로 셀 단위로 데이터를 보여주는 표 그릿 |
| **`TImage`** | 이미지 파일(BMP, ICO 등)을 화면에 표시하는 그림 틀 |
| **`TShape`** | 사각형, 원, 선 등 간단한 도형을 그리는 컴포넌트 |

---

### 3. `Win32` 탭 (윈도우 스타일 현대적 UI) 🟡
윈도우 탐색기나 고급 프로그램 스타일을 연출할 수 있는 컴포넌트 모음입니다.

| 컴포넌트 | 기능 및 비유 |
| :--- | :--- |
| **`TPageControl`** | 탭(Tab) 페이지를 여러 개 나누어 화면 전환하는 탭 컨트롤 |
| **`TImageList`** | 여러 개의 소형 아이콘 이미지를 모아서 관리하는 이미지 리스트 |
| **`TTreeView`** | 폴더 구조처럼 나무(Tree) 가지 모양으로 계층 데이터를 보여주는 뷰 |
| **`TListView`** | 윈도우 탐색기 파일 목록처럼 아이콘/자세히 모드로 데이터를 보여주는 뷰 |
| **`TProgressBar`** | 진행률(0%~100%)을 초록색 막대로 보여주는 프로그레스 바 |
| **`TDateTimePicker`**| 날짜(`2026-07-27`)와 시간 달력을 선택할 수 있는 날짜 선택기 |
| **`TStatusBar`** | 창 최하단에 위치하여 상태 메시지를 보여주는 바 |

---

### 4. `System` 탭 (타이머 & 시스템 제어) 🟢
화면에 보이지 않는 백그라운드 타이머나 그래픽 관련 컴포넌트 모음입니다.

| 컴포넌트 | 기능 및 비유 |
| :--- | :--- |
| **`TTimer`** | **(실무 필수!)** 지정한 시간(예: 1초)마다 코드를 반복 실행하는 시계 타이머 |
| **`TPaintBox`** | 마우스로 그림을 그리거나 캔버스 작업을 할 수 있는 그리기 영역 |

---

### 5. `Dialogs` 탭 (윈도우 대화상자) 🔵
파일을 열거나 저장할 때 나오는 윈도우 표준 팝업 대화상자 모음입니다.

| 컴포넌트 | 기능 및 비유 |
| :--- | :--- |
| **`TOpenDialog`** | "파일 열기" 창을 띄워 사용자가 선택한 파일 경로를 가져오는 창 |
| **`TSaveDialog`** | "다른 이름으로 저장" 창을 띄우는 창 |
| **`TFontDialog`** | 폰트 글꼴 및 크기를 선택하는 창 |
| **`TColorDialog`** | 색상 팔레트 창을 띄워 색상을 고르는 창 |

---

### 6. `Data Access` & `Data Controls` 탭 (DB 연동) 🟣
데이터베이스(Oracle, MS-SQL 등)와 직접 연결하여 화면에 그리드로 띄울 때 씁니다.

| 컴포넌트 | 기능 및 비유 |
| :--- | :--- |
| **`TDataSource`** | DB와 화면 컨트롤을 이어주는 중간 다리 역할 |
| **`TDBGrid`** | DB 테이블 데이터를 엑셀처럼 실시간으로 띄워주는 데이터 그리드 |
| **`TDBEdit`** | DB의 특정 컬럼 값과 자동으로 동기화되는 입력 상자 |

---

### 7. `Indy` 탭 (Indy Clients / Indy Servers / Indy Misc) 🟤
인터넷/네트워크 통신(TCP/IP, HTTP, FTP, Email 소켓 통신)을 담당하는 컴포넌트들입니다.

---

## 💡 시각적(Visual) vs 비시각적(Non-Visual) 컴포넌트의 차이!

1. **시각적(Visual) 컴포넌트**: `TButton`, `TEdit`, `TLabel` 처럼 프로그램을 실행했을 때 **화면에 눈으로 보이는 컴포넌트**입니다.
2. **비시각적(Non-Visual) 컴포넌트**: `TTimer`, `TOpenDialog`, `TDataSource` 처럼 폼 위에는 아이콘으로 놓여 있지만, **프로그램을 실행하면 눈에 보이지 않고 백그라운드에서 동작**하는 컴포넌트입니다.
