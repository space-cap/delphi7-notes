# 00-7. VS Code에서 델파이 7 한글 깨짐 방지 설정 가이드 (EUC-KR 세분화 세팅) ⚙️

> 💡 **후임 개발자를 위한 한 줄 요약**  
> VS Code에서 델파이 코드를 수정하고 저장했더니 델파이 7 IDE에서 한글이 깨지나요? 일반 문서(`.md`)는 **UTF-8**, 델파이 소스(`.pas`, `.dpr`, `.dfm`)만 **EUC-KR**로 자동 저장되도록 인코딩을 분리 설정해야 합니다!

---

## ❓ 왜 델파이 7에서 한글이 깨질까요?

1. **델파이 7 (Delphi 7)**: 2002년에 출시된 ANSI 기반 IDE로, 한국어 윈도우 환경에서 **EUC-KR (CP949)** 인코딩만 인식합니다.
2. **VS Code**: 파일 저장 시 기본값이 **UTF-8**로 설정되어 있습니다.
3. **문제 발생**: VS Code에서 델파이 파일(`.pas`, `.dpr`, `.dfm`)을 수정하고 `Ctrl + S` 저장을 누르면 파일이 UTF-8로 저장되어, 델파이 7에서 열었을 때 `` 나 `븿` 같은 외계어로 한글이 깨지게 됩니다.

---

## 🛠️ 해결책: `.vscode/settings.json` 파일 설정 (프로젝트 공통 적용)

프로젝트 루트 폴더의 `.vscode/settings.json` 파일에 아래 설정을 넣어두면, 후임 개발자가 프로젝트를 열어 저장하더라도 **델파이 파일만 자동으로 EUC-KR로 안전하게 저장**됩니다!

### 📄 `.vscode/settings.json` 설정 코드

```json
{
  "files.encoding": "utf8",         // 기본 문서 및 일반 파일(.md, .json, .py 등)은 UTF-8 적용
  "files.autoGuessEncoding": true,   // 파일 인코딩 자동 감지 켜기
  "files.associations": {
    "*.dpr": "pascal",              // 델파이 프로젝트 파일
    "*.pas": "pascal",              // 파스칼 소스 유닛 파일
    "*.dfm": "pascal",              // 델파이 폼 디자인 파일
    "*.inc": "pascal"               // 인클루드 헤더 파일
  },
  "[pascal]": {
    "files.encoding": "euckr"       // ★ 델파이 관련 파일(pascal)만 EUC-KR 인코딩 자동 지정!
  }
}
```

---

## 🔍 VS Code에서 인코딩 적용 여부 확인하는 법

VS Code 화면 오른쪽 아래(상태 표시줄)를 확인하면 현재 열려 있는 파일의 인코딩을 알 수 있습니다.

| 열어본 파일 종류 | 상태 표시줄 인코딩 확인 | 비 고 |
| :--- | :---: | :--- |
| **`README.md` / `*.json` / `*.py`** | **`UTF-8`** | 일반 개발 문서 및 일반 소스는 UTF-8로 정상 표시 |
| **`*.pas` / `*.dpr` / `*.dfm`** | **`EUC-KR`** | 델파이 소스는 오직 EUC-KR로 자동 표시 및 저장 |

---

## ⚠️ 후임 개발자 필독 주의사항!

1. 델파이 7에서 작업한 뒤 깃(Git)에 올릴 때, `.pas`나 `.dpr` 파일이 UTF-8로 바뀌지 않았는지 항상 확인하세요.
2. 새 델파이 프로젝트나 서브 폴더를 추가할 때도 상위 프로젝트의 `.vscode/settings.json` 설정이 적용되므로 파일별 인코딩 걱정 없이 편하게 저장하셔도 됩니다!
