# 00-3. Delphi 7 IDE 디버깅 완벽 가이드 (F7, F8, F9, Watch) 🐞

> 💡 **초초보자를 위한 한 줄 요약**  
> 디버깅(Debugging)은 **"돋보기"**를 들고 프로그램이 한 줄씩 실행되는 모습을 멈춰서 관찰하는 것입니다. 단축키 4개만 외우면 개발이 10배 쉬워집니다!

---

## 🐞 디버깅(Debugging)이 뭔가요?

프로그램에 에러(버그)가 생겼을 때, 컴퓨터가 코드를 실행하는 순간을 **일시정지**시키고 변수에 무슨 값이 들어있는지 실시간으로 훔쳐보는 기법입니다.

---

## ⌨️ 꼭 외워야 하는 필수 디버깅 단축키 4대장!

| 단축키 | 이름 | 쉬운 설명 |
| :--- | :--- | :--- |
| **`F9`** | **Run (실행)** | 프로그램을 정상적으로 시작하거나, 일시정지 상태에서 계속 진행시킵니다. |
| **`F8`** | **Step Over (한 줄 실행)** | 코드를 **딱 한 줄만 실행**하고 다음 줄에서 멈춥니다. (가장 많이 씀!) |
| **`F7`** | **Step Into (함수 내부 들어가기)** | 실행하려는 코드가 내가 만든 다른 함수라면 **그 함수 내부로 들어가서** 한 줄씩 봅니다. |
| **`F4`** | **Run to Cursor (커서까지 실행)** | 마우스 커서가 찍힌 위치까지 한 번에 달린 뒤 거기서 멈춥니다. |

---

## 🛑 1단계: 브레이크포인트(Breakpoint, 중단점) 걸기

원하는 소스 코드 줄의 왼쪽 맨 가쪽(숫자 옆)을 마우스로 클릭하면 **빨간색 동그라미**가 생깁니다.

* **효과**: 프로그램 실행 중(`F9`) 컴퓨터가 이 빨간 줄을 만나는 순간 **"얼음!"** 하고 딱 멈춥니다.
* **해제**: 빨간 동그라미를 마우스로 다시 한번 누르면 사라집니다.

---

## 🔍 2단계: 변수에 들어있는 값 실시간으로 보기 (`Watch` & `Tooltip`)

프로그램이 일시정지(`F8`로 한 줄씩 이동 중) 상태일 때:

1. **마우스 올려놓기 (Tooltip)**: 
   - 변수 이름 위에 마우스를 1초 동안 올려두면 팝업으로 `Age = 25`처럼 현재 값이 바로 보입니다!
2. **Watch Window (실시간 감시 창 - `Ctrl + F7`)**:
   - `Ctrl + F7`을 누르고 궁금한 변수 이름을 적으면 하단 창에 변수의 값이 실시간으로 변경되는 모습이 계속 찍힙니다.

---

## 🎯 초초보자를 위한 3단계 디버깅 실전 시나리오

1. 에러가 날 것 같은 코드 위치 줄에 **`F5`**(또는 마우스 클릭)로 **빨간 줄(중단점)**을 답니다.
2. **`F9`**를 눌러 프로그램을 실행하고 에러가 나는 버튼을 누릅니다.
3. 프로그램이 빨간 줄에서 딱 멈추면, **`F8`**을 톡-톡- 누르며 한 줄씩 내려가면서 마우스를 올려 변수 값을 확인합니다!
