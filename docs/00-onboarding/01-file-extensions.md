# 00-1. 델파이 7 주요 파일 확장자 구조 (.dpr, .pas, .dfm, .dcu) 📂

> 💡 **초초보자를 위한 한 줄 요약**  
> 델파이 프로젝트 폴더를 열었을 때 수많은 파일이 나와도 당황하지 마세요! **"집 짓기"**에 비유하면 아주 쉽습니다.

---

## 🏠 델파이 파일들을 '집 짓기'로 이해해 봅시다!

델파이 프로젝트를 처음 만들거나 열어보면 뒤에 `.pas`, `.dfm`, `.dpr` 같은 생소한 알파벳(확장자)이 붙은 파일들이 잔뜩 생깁니다. 

각 파일들이 어떤 역할을 하는지 진짜 쉽게 알아봅시다!

---

### 1. 🔑 `.dpr` (Delphi Project File) - "집 전체 건설 총감독 문서"
* **원래 이름**: Delphi Project (델파이 프로젝트)
* **쉬운 비유**: **"집의 건물 전체 설계도 & 대문"**
* **역할**: 
  - 프로그램이 처음 시작될 때 **가장 먼저 열리는 파일**입니다.
  - "이 프로그램에는 A화면, B화면이 있고, 제일 먼저 A화면을 띄워라!" 하고 전체를 총괄하는 역할을 합니다.
* **초보자 팁**: 보통 델파이 프로그램을 열 때 이 `.dpr` 파일을 닥블클릭해서 엽니다!

---

### 2. 📝 `.pas` (Pascal Unit) - "실제 일하는 요리 레시피 (소스 코드)"
* **원래 이름**: Pascal Unit File (파스칼 유닛 파일)
* **쉬운 비유**: **"버튼을 눌렀을 때 무슨 일을 할지 적어둔 행동 지침서(레시피)"**
* **역할**: 
  - 우리가 프로그래밍할 때 **가장 많이 보게 될 글자(코드) 파일**입니다.
  - "버튼을 누르면 창을 닫아라", "마우스를 올리면 글자 색을 빨간색으로 바꿔라" 같은 실제 명령을 적는 곳입니다.

---

### 3. 🎨 `.dfm` (Delphi Form File) - "방 인테리어 가구 배치도 (화면 모양)"
* **원래 이름**: Delphi Form (델파이 폼)
* **쉬운 비유**: **"방에 침대, 책상, TV를 어디 놓았는지 그려둔 인테리어 배치도"**
* **역할**: 
  - 화면에 보이는 버튼의 위치, 크기, 글자 색상, 창의 너비 같은 **디자인 정보**가 저장되는 파일입니다.
  - `.pas` 파일 하나당 쌍둥이처럼 `.dfm` 파일이 한 개씩 짝을 이룹니다.
* > ⚠️ **초초보자 필독 팁!**  
  > 델파이에서 화면(Form)을 고치면 `.pas` 파일과 `.dfm` 파일이 **동시에** 수정됩니다. 두 파일은 콤비(Set)입니다!

---

### 4. ⚙️ `.dcu` (Delphi Compiled Unit) - "컴퓨터가 읽기 쉽게 번역해 둔 중간 결과물"
* **원래 이름**: Delphi Compiled Unit (델파이 컴파일된 유닛)
* **쉬운 비유**: **"사람이 적은 요리책(.pas)을 로봇(컴퓨터)이 빠르게 읽을 수 있게 미리 번역해 둔 파일"**
* **역할**: 
  - 우리가 코드를 실행(`F9`)하면 델파이가 자동으로 만들어내는 임시 파일입니다.
* **초보자 팁**: 
  - 지워도 실행하면 다시 생깁니다! 
  - 깃(Git)에 올릴 때 이 `.dcu` 파일은 제외(.gitignore)해야 합니다.

---

## 📊 한눈에 비교하는 델파이 주요 파일 요약표

| 확장자 | 무슨 파일인가요? | 내가 직접 고치나요? | 깃(Git)에 올려야 하나요? |
| :--- | :--- | :---: | :---: |
| **`.dpr`** | 프로그램 시작점 (프로젝트 파일) | ⭕ 네 (가끔) | ⭕ 네, 올려야 해요 |
| **`.pas`** | 행동 지침서 (실제 코드) | ⭕ **네! 가장 많이 고쳐요** | ⭕ 네, 올려야 해요 |
| **`.dfm`** | 화면 디자인 정보 (가구 배치) | ⭕ 네 (마우스로 그리면 자동 변경) | ⭕ 네, 올려야 해요 |
| **`.dcu`** | 컴퓨터용 번역 임시 파일 | ❌ 아니오 (자동 생성됨) | ❌ **절대 올리면 안 돼요!** |
| **`.exe`** | 최종 완성된 실행 프로그램 | ❌ 아니오 (결과물) | ❌ 올리지 않아요 |

---

## 🎯 초초보자를 위한 실무 3줄 요약!

1. 델파이 프로젝트를 열 때는 **`.dpr`** 파일만 닥블클릭하면 끝!
2. 내가 코딩할 때는 **`.pas`**(코드)와 **`.dfm`**(화면) 딱 두 가지만 신경 쓰면 됩니다!
3. **`.dcu`** 나 **`.exe`** 는 컴퓨터가 알아서 만드는 파일이니 신경 쓰지 않아도 됩니다!
