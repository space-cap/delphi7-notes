# 00-4. DFM 파일 관리 및 Git 형상관리 주의사항 (Text DFM 설정) ⚠️

> 💡 **초초보자를 위한 한 줄 요약**  
> 델파이 화면 디자인 파일(`.dfm`)을 텍스트(Text) 모드로 안 바꿔두면, **깃(Git)으로 팀원들과 협업할 때 소스 코드가 깨지거나 비교가 안 되는 대참사**가 일어납니다!

---

## 😱 DFM 파일이 바이너리(Binary)면 왜 문제가 되나요?

델파이 7 기본 설정에서는 화면 모양 정보인 `.dfm` 파일을 사람 눈으로 읽을 수 없는 **이진 파일(Binary File, 깨진 암호 문자열 형태)**로 저장하기도 합니다.

만약 이진 상태로 깃(Git)에 올리면:
* ❌ 깃허브에서 내가 화면 디자인을 어떻게 바꿨는지(Diff) 비교가 전혀 안 됩니다!
* ❌ 다른 팀원이 폼을 수정했을 때 충돌(Conflict)이 나면 해결하기가 거의 불가능합니다.

---

## 🛠️ 해결책 1: 델파이 IDE에서 'Text DFM' 설정 확인하기

델파이 7 환경에서 마우스 오른쪽 클릭 한 번으로 `.dfm` 파일을 **글자(Text) 형태**로 바꿀 수 있습니다.

1. 델파이 7에서 화면(Form) 디자인 창을 엽니다.
2. 화면 빈 곳에 마우스 오른쪽 버튼을 누릅니다.
3. 팝업 메뉴 맨 아래에 있는 **`Text DFM`** 항목에 **체크(v)**가 되어 있는지 확인합니다!
4. 체크되어 있으면 이제 `.dfm` 파일이 아스키 텍스트로 저장되어 깃(Git)에서 예쁘게 수정 내역이 보입니다.

---

## ⌨️ 단축키 꿀팁: `Alt + F12` (디자인 창 <-> 텍스트 코드 전환)

델파이 화면 디자인 창에서 **`Alt + F12`** 키를 누르면:
* 🎨 버튼이 있는 화면 모드에서 ➡️ `object Form1: TForm1 ... end` 형태의 **텍스트 코드 모드**로 변신합니다!
* 다시 `Alt + F12`를 누르면 디자인 화면으로 돌아옵니다.

> 💡 **언제 쓰나요?**  
> 화면 버튼이 갑자기 이상한 데로 도망갔거나, 텍스트로 폼 속성을 직접 고치고 싶을 때 쓰면 아주 유용합니다!

---

## 🎯 초초보자를 위한 Git 협업 수칙 3가지

1. **`Text DFM` 항목이 체크되어 있는지 확인하고 저장하기!**
2. 화면 디자인만 살짝 건드렸는데도 `.dfm` 파일 위치 정보가 바뀔 수 있으니 **내가 안 건드린 폼은 안 올리기!**
3. 깃에 올릴 때는 항상 `.pas` 파일과 `.dfm` 파일을 세트로 함께 커밋하기!
