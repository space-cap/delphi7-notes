# 00-5. 로컬 빌드 환경 구축 노트 (Search Path & Library Path 설정) 🛠️

> 💡 **초초보자를 위한 한 줄 요약**  
> 사수한테 소스 코드를 받았는데 실행(`F9`)하자마자 **"File not found..."** 에러가 나나요? 컴퓨터에게 부품(컴포넌트)들이 어디 숨어있는지 길(Path)을 안 가르쳐줘서 그렇습니다!

---

## ❓ 왜 'File not found' 에러가 나나요?

델파이 코딩을 할 때 다른 사람이 만들어둔 유닛(`.pas` 나 `.dcu`)을 불러와서 쓰는데, 델파이 IDE가 그 파일이 내 컴퓨터 **어느 폴더 경로에 있는지 찾지 못해서** 일어나는 대표적인 빌드 에러입니다.

마치 친구한테 "내 책상 두 번째 서랍에서 열쇠 좀 가져다줘" 하고 정확한 위치를 알려주지 않은 것과 같습니다.

---

## 🛠️ 해결법: 2가지 경로(Path) 설정 방법

### 1. Library Path (모든 델파이 프로젝트 공통 설정) 🌐
외부 써드파티 컴포넌트(DevExpress, FastReport 등)를 설치한 폴더 위치를 **델파이 IDE 전체**에 등록하는 방법입니다.

* **설정 순서**:
  1. 델파이 상단 메뉴 ➡️ **`Tools`** ➡️ **`Environment Options`** 선택
  2. **`Library`** 탭 클릭
  3. **`Library Path`** 오른쪽의 `...` 버튼 클릭
  4. 외부 컴포넌트 소스(`.dcu`, `.pas`)가 들어있는 **폴더 경로를 찾아 추가(Add)**하고 OK 버튼 누르기!

---

### 2. Search Path (현재 내 특정 프로젝트 전용 설정) 🎯
우리 회사 프로젝트 폴더 안에 별도로 모아둔 공통 함수 모듈(`Common/Utils` 등) 경로를 설정할 때 씁니다.

* **설정 순서**:
  1. 델파이 상단 메뉴 ➡️ **`Project`** ➡️ **`Options`** 선택 (단축키: `Ctrl + Shift + F11`)
  2. **`Directories/Conditionals`** 탭 클릭
  3. **`Search Path`** 항목에 내 프로젝트 하위 공통 폴더 경로 추가하기!

---

## 🕵️‍♂️ 사수에게 예의 바르게 질문하는 팁!

프로젝트를 받았는데 실행이 안 될 때 당황하지 말고 사수에게 이렇게 여쭤보세요:

> **"사수님! 프로젝트 실행 시 `File not found` 에러가 발생하는데, 혹시 제가 추가로 등록해야 할 `Library Path` 경로나 외부 컴포넌트 위치가 어디일까요?"**

👉 이 질문 한 마디만으로 사수님은 **"오! 이 인턴 델파이 개념을 기본부터 잘 아는 친구네!"** 하고 감탄하실 겁니다! 🤩
