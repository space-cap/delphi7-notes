# 00-2. 실무 써드파티 컴포넌트 파악 (DevExpress, FastReport 등) 🧩

> 💡 **초초보자를 위한 한 줄 요약**  
> 델파이 기본 부품(컴포넌트)만으로는 밋밋합니다. 실무에서는 외부 회사에서 만든 **"레고 고급 확장 패키지(써드파티 컴포넌트)"**를 추가해서 화려하고 강력한 프로그램을 만듭니다!

---

## 🧩 '써드파티(Third-Party) 컴포넌트'란 무엇인가요?

델파이를 만든 회사(1st Party)와 사용자(2nd Party) 외에 **제3의 외부 전문 개발회사(3rd Party)**에서 만든 **확장 부품 도구 모음**을 의미합니다.

마치 순정 자동차에 사제 최고급 오디오나 루프탑을 설치하는 것처럼, 델파이 프로그램의 디자인과 기능을 한 차원 높여줍니다.

---

## 🏆 실무 델파이 7 프로젝트 빈출 Top 4 써드파티!

### 1. 📊 DevExpress (ExpressQuantumGrid 등) - "엑셀급 초고성능 그리드"
* **뭐 하는 도구인가요?**: 데이터를 표(테이블) 형태로 보여줄 때 쓰는 **끝판왕 그리드** 컴포넌트입니다.
* **실무 특징**:
  - 엑셀처럼 컬럼(열)별로 필터링, 정렬, 그룹핑, 합계 계산이 클릭 몇 번으로 가능합니다.
  - 델파이 7 실무 프로젝트의 80% 이상이 이 DevExpress 그리드를 사용합니다.

### 2. 🖨️ FastReport & QuickReport - "영수증/명세서 인쇄 마법사"
* **뭐 하는 도구인가요?**: 거래명세서, 영수증, 납품서, 결재 문서 등을 **종이에 출력(인쇄)하거나 PDF로 변환**할 때 씁니다.
* **실무 특징**:
  - 화면에 보이는 대로 출력물을 디자인하는 리포트 디자이너 창을 제공합니다.
  - "이 영수증 양식 글자 좀 키워주세요" 업무를 받으면 보통 이 녀석을 열게 됩니다!

### 3. 🌐 Indy Components & ZeosDBO - "통신 & DB 연결의 맥가이버"
* **Indy**: 인터넷 통신(HTTP, FTP, TCP/UDP 소켓)을 손쉽게 해주는 부품 모음
* **ZeosDBO**: MySQL, Oracle, PostgreSQL 등 다양한 DB에 ADO 없이 직연결할 수 있게 돕는 도구

### 4. 🎨 TMS Components - "화려한 윈도우 UI 패키지"
* 델파이 7 기본 버튼이나 메뉴는 심심하게 생겼습니다. TMS 패키지를 쓰면 현대적인 툴바, 탭 메뉴, 화려한 버튼 디자인을 쉽게 적용할 수 있습니다.

---

## 🔍 사수 프로젝트에서 써드파티 찾는 법!

인턴으로 입사해서 프로젝트를 열었을 때 어떤 써드파티를 쓰는지 알아보려면:

1. **상단 툴바(Component Palette) 확인**: `cxGrid` (DevExpress), `frxReport` (FastReport) 같은 탭이 있는지 확인합니다.
2. **소스 코드 맨 위 `uses` 절 확인**:
   ```pascal
   uses
     cxGrid, cxClasses, // <- DevExpress 쓰시는군요!
     frxClass, frxDBSet; // <- FastReport 쓰시는군요!
   ```
