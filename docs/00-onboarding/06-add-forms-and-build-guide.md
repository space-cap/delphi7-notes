# 00-6. [왕초보 가이드] 델파이 7에서 폼 2개 추가하고 빌드(실행)하기 🐣🚀

> 💡 **초초보자를 위한 한 줄 요약**  
> 클릭 몇 번으로 화면(Form)을 2개 만들고, 버튼을 누르면 두 번째 화면이 짠! 하고 띄워지게 만든 뒤 프로그램으로 완성(빌드)하는 전체 과정을 하나씩 따라 해봅시다!

---

## 🎯 오늘 만들어볼 프로그램 목표
1. 메인 화면(**`Form1`**)에 버튼을 하나 놓습니다.
2. 두 번째 화면(**`Form2`**)을 새로 추가합니다.
3. 메인 화면의 버튼을 누르면 **`Form2`가 나타나게** 코드를 작성합니다.
4. 프로그램을 **빌드(Build) 및 실행(`F9`)** 합니다!

---

## 🛠️ 1단계: 델파이 7에서 새로운 프로젝트 만들기

1. 델파이 7을 실행합니다.
2. 상단 메뉴에서 **`File` ➔ `New` ➔ `Application`**을 클릭합니다.
3. 짜잔! 화면 한가운데 모눈종이 같은 바탕에 **`Form1`** 창이 자동으로 생깁니다.

---

## 🖼️ 2단계: 첫 번째 화면(Form1) 꾸미기

1. 화면 오른쪽(또는 상단) 컴포넌트 팔레트에서 **`Standard`** 탭을 클릭합니다.
2. **`OK`** 또는 **`Button`** 모양 아이콘(Button 컴포넌트)을 마우스로 클릭합니다.
3. `Form1` 화면 위를 클릭하여 버튼을 배치합니다. (`Button1` 생성)
4. 왼쪽 **Object Inspector** 창에서 `Caption` 항목을 찾아 글자를 **`두 번째 화면 열기`**로 바꿔줍니다.

---

## ➕ 3단계: 두 번째 화면(Form2) 추가하기 (핵심!)

새로운 화면을 하나 더 추가하는 방법은 정말 쉽습니다.

### 📌 폼 추가 방법 (2가지 중 편한 것 사용)
* **방법 A (메뉴 클릭)**: 상단 메뉴 **`File` ➔ `New` ➔ `Form`** 클릭!
* **방법 B (아이콘 클릭)**: 상단 툴바에서 📄 **[New Form]** 아이콘 클릭!

👉 클릭하면 `Form1` 위에 똑같이 생긴 새 화면 **`Form2`**가 뿅! 등장합니다.

---

## 🔗 4단계: Form1에서 Form2를 불러오도록 연결하기

델파이에선 **"A 화면이 B 화면을 띄우려면, A 화면이 B 화면의 존재를 알고 있어야 합니다."**

### 1) Form1 소스 코드 열기
- `Form1` 화면을 클릭하고, **`F12`** 키를 누르면 화면 디자인 모드 ↔ 소스 코드 모드로 전환됩니다.

### 2) `uses` 절에 Unit2 추가하기 (가장 중요! ⭐)
- `Form2`에 해당하는 파스칼 소스 파일 이름은 기본적으로 **`Unit2`**입니다.
- `Unit1.pas` 소스 코드의 `implementation` 아래에 `uses Unit2;`를 적어줍니다.

> 💡 **초보자를 위한 더 쉬운 팁!**  
> `Form1`이 켜진 상태에서 **`File` ➔ `Use Unit...`** (단축키 `Alt + F11`)을 누르고 **`Unit2`**를 선택한 후 OK를 누르면 델파이가 알아서 연결해 줍니다!

### 3) 버튼 클릭 이벤트 작성하기
1. `Form1` 화면의 버튼을 **마우스로 더블클릭**합니다.
2. 코드 창이 열리면서 아래처럼 이벤트 함수가 만들어집니다. `begin`과 `end;` 사이에 **`Form2.Show;`** 한 줄을 적어줍니다!

```pascal
procedure TForm1.Button1Click(Sender: TObject);
begin
  // Form2 창을 화면에 나타나게 합니다!
  Form2.Show; 
end;
```

> 💡 **참고 (Show vs ShowModal)**
> - `Form2.Show;` : Form2가 열려도 뒤의 Form1을 클릭할 수 있습니다.
> - `Form2.ShowModal;` : Form2가 닫히기 전까지는 뒤의 Form1을 클릭할 수 없는 "팝업창" 스타일입니다!

---

## ⚙️ 5단계: 어떤 화면을 먼저 띄울지 확인하기 (Main Form)

프로그램이 켜질 때 **Form1**이 먼저 켜질지, **Form2**가 먼저 켜질지 결정하는 곳입니다.

1. 상단 메뉴 **`Project` ➔ `Options`** (단축키 `Ctrl + Shift + F11`)를 누릅니다.
2. **`Forms`** 탭을 클릭합니다.
3. **`Main form`** 항목이 **`Form1`**로 되어 있는지 확인합니다. (바꾸고 싶다면 선택해서 변경 가능!)

---

## 🔨 6단계: 빌드(Build) 및 실행하기 🚀

이제 만든 프로그램을 컴퓨터가 읽을 수 있도록 만들고 실행해 봅시다!

| 구 분 | 단축키 | 하는 일 |
| :--- | :---: | :--- |
| **컴파일 (Compile)** | `Ctrl + F9` | 코드에 문법 에러가 없는지 검사합니다. |
| **빌드 (Build All)** | `Project ➔ Build All` | 프로젝트 전체 파일을 처음부터 새로 깔끔하게 컴파일합니다. |
| **실행 (Run)** | **`F9`** | 컴파일 + 빌드 후 **프로그램을 즉시 켜서 테스트**합니다! |

### 🎉 실행해 보기!
1. 키보드의 **`F9`** 키를 누릅니다!
2. 프로그램이 켜지면서 `Form1` 화면이 떠오릅니다.
3. **`[두 번째 화면 열기]`** 버튼을 클릭해 봅니다.
4. 짜잔! `Form2` 화면이 부드럽게 새로 열리는 것을 확인하실 수 있습니다!

---

## ⚠️ 왕초보가 자주 겪는 오류 & 대처법 3가지!

### Q1. `Form2.Show;` 라고 적었는데 `Declaration not found` 에러가 나요!
👉 `Unit1`에서 `Unit2`를 참조(`uses`)하지 않아서 그렇습니다!  
`Form1` 화면에서 **`Alt + F11`**을 눌러 `Unit2`를 추가해 주세요.

### Q2. 폼 화면이 사라졌어요! 어디 갔죠?
👉 **`Shift + F12`** (폼 목록) 키를 누르거나, **`Ctrl + F12`** (유닛 소스 목록) 키를 누르면 프로젝트 안의 모든 화면을 다시 찾아 열 수 있습니다!

### Q3. 만든 폼을 파일로 저장하고 싶어요.
👉 **`File` ➔ `Save All`** (단축키 `Shift + Ctrl + S`)을 눌러 프로젝트 파일(`.dpr`)과 폼 파일들(`.pas`, `.dfm`)을 한꺼번에 저장하세요!
