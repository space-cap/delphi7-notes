# 01-2. 변수 선언, 자료형 및 연산자 📦

> 💡 **초초보자를 위한 한 줄 요약**  
> 변수(Variable)는 **"값을 담아두는 이름표 붙은 상자"**입니다. 델파이에서는 상자를 쓰기 전에 무조건 **`var`** 구역에서 상자를 미리 준비해야 합니다!

---

## 📦 델파이에서 변수 만드는 공식: `var`

C 언어나 자바와 달리 델파이는 코드 아무 데서나 변수를 즉석으로 만들 수 없고, 반드시 코드 위쪽 **`var`** 구역에 미리 신고해야 합니다!

```pascal
var
  MyAge: Integer;      // 정수(숫자) 담는 상자
  MyName: String;      // 문장(글자) 담는 상자
  IsStudent: Boolean;  // 참/거짓 담는 상자
```

---

## 🏷️ 초초보자가 자주 쓰는 델파이 대표 자료형(Type) 4대장

| 자료형 (Type) | 담을 수 있는 값 | 예시 | 쉬운 비유 |
| :--- | :--- | :--- | :--- |
| **`Integer`** | 정수 (소수점 없는 숫자) | `10`, `0`, `-5` | 사과 개수 담는 상자 |
| **`String`** | 글자 / 문장 | `'홍길동'`, `'델파이 7'` | 이름표 스티커 |
| **`Double`** | 실수 (소수점 있는 숫자) | `3.14`, `99.5` | 저울 무게 담는 상자 |
| **`Boolean`** | 참 / 거짓 | `True`, `False` | 스위치 ON/OFF |

---

## 🛑 델파이만의 특이한 점 2가지!

### 1. 값 넣기 기호는 `=` 이 아니라 `:=` (콜론+이퀄)!
* 다른 언어에서는 `Age = 20;` 이라고 쓰지만, 델파이에서는 **`:=`** 기호를 써서 오른쪽 값을 왼쪽에 집어넣습니다!
  ```pascal
  MyAge := 25; // MyAge 상자에 25를 집어넣는다!
  ```

### 2. 문자는 따옴표(`' '`) 하나만 씁니다!
* 큰따옴표(`" "`)가 아니라 **작은따옴표(`' '`)**로 글자를 감쌉니다.
  ```pascal
  MyName := '홍길동'; // Correct!
  ```

---

## ➕ 델파이 주요 연산자 (대입, 사칙연산, 비교)

### 사칙 연산
* `+` (더하기), `-` (빼기), `*` (곱하기)
* `/` (실수 나누기: 결과가 소수점으로 나옴 -> `7 / 2 = 3.5`)
* `div` (정수 나누기 몫 -> `7 div 2 = 3`)
* `mod` (나누기 나머지 -> `7 mod 2 = 1`)

### 비교 연산자 (같다, 다르다)
* `=` (같다! `if A = B then`)
* `<>` (다르다! `if A <> B then`)

---

## 💻 쉽게 따라 해보는 변수 코드 예제

```pascal
procedure CalculateSalary;
var
  HourlyWage: Integer; // 시급
  WorkingHours: Integer; // 일한 시간
  TotalPay: Integer; // 총지급액
begin
  HourlyWage := 10000;
  WorkingHours := 8;
  
  // 계산해서 상자에 넣기!
  TotalPay := HourlyWage * WorkingHours;
  
  ShowMessage('오늘 일당은 ' + IntToStr(TotalPay) + '원입니다!');
end;
```
