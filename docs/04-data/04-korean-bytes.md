# 04-4. 한글 2Byte(CP949) 처리 및 문자열 잘림(자소 파괴) 방지 ✂️

> 💡 **초초보자를 위한 한 줄 요약**  
> Delphi 7에서 한글은 **2바이트**입니다. 짝수 바이트로 안 자르고 홀수 위치(1Byte 위치)에서 싹둑 자르면 **한글이 깨지고 이상한 외계어 문자**로 변신합니다!

---

## 😱 왜 한글이 깨지나요? (자소 파괴 현상)

한글 '홍'이라는 글자는 `0xB8, 0xAE` 두 개의 바이트가 합쳐져서 만든 글자입니다.

만약 바이트 길이를 잘못 계산해서 `0xB8` 하나만 자르면, 뒤에 남아있는 바이트와 엉뚱하게 결합하여 `홍` 대신 `?` 나 깨진 외계어 특수문자가 튀어나오게 됩니다!

```pascal
var
  S, Sub: String;
begin
  S := '홍길동'; // 총 6 Byte (2Byte * 3)
  
  // ❌ 3 Byte 위치에서 어정쩡하게 자르면?
  Sub := Copy(S, 1, 3); // '홍' + '길'의 앞쪽 1Byte만 잘림!
  ShowMessage(Sub); // 💥 출력 결과: "홍?" (한글 깨짐 발생!)
end;
```

---

## 🛡️ 안전하게 한글을 자르는 2가지 방법!

### 1. 짝수 바이트(2Byte 단위)로 자르기
* 한글을 자를 때는 잘라낼 길이(`Length`)를 항상 **2의 배수(2, 4, 6, 8...)**로 맞추어 자릅니다!

### 2. `AnsiPosition` 및 `ByteType` 함수 활용
델파이가 제공하는 **`ByteType`** 함수를 쓰면 현재 위치가 한글의 첫 번째 바이트(`mbLeadByte`)인지 두 번째 바이트(`mbTrailByte`)인지 판단할 수 있습니다!

```pascal
uses
  SysUtils;

if ByteType(S, 3) = mbLeadByte then
  // 한글의 첫 번째 바이트임!
```
