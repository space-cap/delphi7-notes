# 03-3. 포인터와 동적 메모리 할당 📍

> 💡 **초초보자를 위한 한 줄 요약**  
> **포인터(Pointer)**는 값 자체가 아니라 **"그 값이 있는 집 주소(메모리 번지수)"**를 가리키는 화살표입니다!

---

## 📍 포인터의 기본 개념 (집 주소 비유)

* **일반 변수 (`Age := 20`)**: 상자 안에 진짜 숫자 20이 들어있음.
* **포인터 변수 (`P`)**: 상자 안에 **"서울특별시 강남구 ... (메모리 주소)"**가 들어있음.

---

## 🔑 델파이 포인터의 2대 기호: `@` 와 `^`

1. **`@` (주소 알아내기)**: "이 변수의 메모리 집 주소가 몇 번지니?"
2. **`^` (주소 찾아가기 - 역참조)**: "이 주소 번지수로 진짜 찾아가서 알맹이 값을 꺼내라!"

```pascal
var
  Num: Integer;
  P: ^Integer; // Integer를 가리키는 포인터 변수 선언!
begin
  Num := 100;
  
  P := @Num; // Num의 메모리 주소를 P에 집어넣음!
  
  // P가 가리키는 주소로 진짜 찾아가서(^) 값을 출력!
  ShowMessage(IntToStr(P^)); // 출력: 100
end;
```

---

## 🧱 동적 메모리 할당: `GetMem` 과 `FreeMem`

필요한 만큼 메모리를 즉석에서 빌려 쓰고, 사용이 끝나면 반납하는 명령입니다.

```pascal
var
  P: Pointer;
begin
  // 1. 1024 Byte(1KB) 크기의 메모리를 즉석 빌림!
  GetMem(P, 1024);
  try
    // 빌린 메모리 P 사용...
  finally
    // 2. 다 썼으니 반드시 반납!
    FreeMem(P, 1024);
  end;
end;
```

---

## 🎯 초초보자를 위한 실무 팁

실무 델파이 7 코드에서는 C 언어만큼 포인터를 직접 쓸 일이 많지는 않습니다. 

다만 **Win32 API 호출**이나 **C/C++ DLL 연동**을 할 때 포인터(`PChar`, `Pointer`)가 자주 등장하므로 개념만 이해해 두시면 충분합니다!
